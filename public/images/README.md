# Public Images Directory

This is the public asset directory! It is statically served by the Vite application, meaning any file placed here can be accessed starting directly with `/images/...`.

**How to manage files:**
1. You can upload files directly into this `/public/images` folder using the file explorer sidebar on the left.
2. If you upload a file called `my_motocross_pic.jpg` you can render it inside your react app by pointing an image tag to it like this: `src="/images/my_motocross_pic.jpg"`.

Currently, this folder stores the offline `.jpg` assets used for the Gallery, Events, and Hero background!
